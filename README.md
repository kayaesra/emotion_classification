The project handles a multi-class classification task involving six emotional states.📊 Dataset: dair-ai/emotionVolume: 20,000 samples (16k Train / 2k Val / 2k Test).Classes: Sadness (0), Joy (1), Love (2), Anger (3), Fear (4), Surprise (5).Challenge: The dataset is unbalanced, with "Joy" and "Sadness" being the majority classes, which significantly impacts the model's ability to recognize minority emotions like "Surprise".🛠️ Technical Implementation1.
